GeoPixel vs FlyDea — Posicionamento Competitivo

Análise de gaps críticos para ganhar licitações de GovTech

GeoPixel (Referência Madura)

✅ Consolidated

  • WebGIS enterprise (Cesium, ícones próprios)
  • CTM com 10+ anos de UX municipal
  • IPTU/PGV estável, auditado
  • Mobile nativo (iOS/Android)
  • Portal cidadão produção
  • E2E ci/cd, deploy automatizado
  • Backup/DR documentado

⚠️ Pontos de vulnerabilidade

  • Menos modular (monólito)
  • Stack proprietário = vendor lock-in
FlyDea (OpenStack)

✅ Fortalezas

  • Modular (NestJS + Next.js)
  • Aberto (dados em SQL padrão)
  • Bom progresso em core (4/5)
  • Infraestrutura moderna

🔴 Gaps críticos para licitação

  • Mobile (2/5) — campo precisa
  • CI/CD — nenhuma prova E2E automatizada
  • Compliance — sem auditoria visível
  • Notificações/cartas — não produção
  • UX ops — empty states, wizard completo

Próxima decisão:

Para ganhar licitações, qual desses gaps é mais crítico pra sua estratégia?

A

Mobile First (Vistorias em Campo)

Prioridade: demo mobile nativo + sincronização offline. Prefeituras veem campo com confiança.

B

Reliability & Compliance

Prioridade: E2E CI/CD, backup/DR visível, auditoria legal. Sinaliza "operacional confiável" vs GeoPixel.

C

Balanced: 40% cada + UX

Mobile MVP + CI/CD proof de maneira rápida, depois refina UX. Cobertura ampla com menos profundidade.
