# Bid Winning Readiness

## Executive Summary

The platform is now credible for municipal bids scoped around:
- CTM
- PGV
- digital certidions
- digital processes
- monitoring and alerts
- field ops minimum
- citizen service minimum
- public works minimum
- cemetery minimum
- observatory minimum
- portal coexistence via signed deep links and exchange flow
- portal coexistence with OIDC-ready authorize/callback handoff
- configurable executive dashboard widgets
- offline-first field collection with queued sync, evidences, and clear status
- observatory with comparative decision metrics

## What Makes It Competitive
- multi-tenant architecture
- RBAC and tenant guard
- audit/history on critical modules
- map-first UX
- executive dashboard
- observatory
- integration hub for portal coexistence
- institutional readiness summary with explicit remaining dependency

## Remaining Bid Risks
- external portal SSO is prepared with an OIDC-ready homologation flow, but not yet integrated with a real municipal IdP
- external feeds for monitoring are still not production-grade
- offline-first mobile now carries evidences, but conflict resolution remains basic
- some modules are minimum viable, not enterprise mature
- federation with a real IdP remains the main institutional risk for broad tenders

## Commercial Positioning
Do not sell this as a clone of a mature suite.
Sell it as a modular municipal operating platform with:
- stronger UX
- clearer traceability
- better demo flow
- stronger integration story
